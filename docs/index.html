Merab

A local runtime for orchestrating OS-level AI agents, splitting work into parallel subtasks, and preserving the session trail.

View on GitHub Run locally

Runtime shape

Plan, execute, track, continue.

Planner DAG

Breaks a task into persona-specific subtasks with dependencies.

Local tools

Connects agents to filesystem, shell, git, HTTP, MCP, and A2A.

Session memory

Stores conversations, artifacts, jobs, token usage, and context.

Quickstart

Run the daemon, then ask Merab.

cargo build --workspace
cargo run -p merab-daemon --bin merabd
cargo run -p merab-cli --bin merab -- ask "summarize this repo"
